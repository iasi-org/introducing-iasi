Introducing IASI

Intelligent Assisted Software Engineering

Because when implementation costs less and less, knowledge becomes more and more valuable.

What is IASI?

Engineering for a world where intelligent systems are part of the process.

IASI is an open initiative exploring how software engineering changes when intelligent systems stop being occasional tools and become a real and natural part of engineering work.

It is not about replacing engineering. It is about rethinking how we define problems, preserve knowledge, make decisions, execute work and verify results.

The question is no longer how to add AI to the old process, but what engineering process this new reality requires.

IASI is the boundary

What comes from outside enters as input. Inside IASI it is understood, engineered and materialized. What leaves is output.
