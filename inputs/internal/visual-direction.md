## Visual direction

The current visual direction for **Introducing IASI** is dark, technical and editorial.

The dark identity is accepted as the working direction for this presentation, but it is not yet a universal visual rule for every IASI artifact.

## Typography

Preferred typography:

- **IBM Plex Sans** for headings and normal presentation text;
- **IBM Plex Mono** for technical labels, small annotations and system-like text.

## Cover

The cover currently contains:

- `Introducing IASI`;
- `Intelligent Assisted Software Engineering`;
- a circular `START` control;
- a short epigraph at the bottom.

The phrase `A new layer for building software` has been rejected and must not be used.

The current epigraph is:

*Because when implementation costs less and less, knowledge becomes more and more valuable.*

The epigraph should behave like the short quotations used in books:

- discreet;
- italic;
- preferably on one line;
- visually separated by typography and tone rather than by borders or decorative elements.

## Colour and contrast

Current direction:

- near-black / deep green-black background;
- very light main text;
- acid green as a strong accent;
- cyan as a secondary accent.

White may be used for detail popups to create a clear visual layer above the dark presentation.

## Popups

Interactive detail panels should currently use:

- white background;
- dark text;
- no blurred presentation background;
- strong but simple hierarchy;
- recognizable icons where visual examples are more useful than text cards.

## Graphic language

The current presentation favours:

- boxes for bounded concepts;
- arrows for flow;
- larger containing boxes for system boundaries;
- recognizable icons for formats, destinations and actions;
- restrained animation.

Decorative graphics should not compete with the idea being explained.

## Current status

This is a working visual direction accepted through human review.

It may continue to evolve while the presentation is developed.
